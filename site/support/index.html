Support

Bellterm is a native iOS and Android client for Herdr, over SSH.

Write to fyibmsd+apple@gmail.com and say what happened, which phone and iOS or Android version you use, and what the screen showed. If you can, attach a screenshot. Bugs and feature requests can also go to GitHub Issues.

Common questions

What do I need before the first connection?

A machine you can reach over SSH, with Herdr 0.9.0 or later and /bin/sh on it. On iPhone, install the beta from TestFlight; on Android 10 or newer, download the APK. Jump hosts need SSH with TCP forwarding allowed.

How do I connect the first time?

On first launch Bellterm generates an Ed25519 key for the device. Open Keys & certificates, copy the public key, add it to ~/.ssh/authorized_keys on the host, then add the host as a node — or import your ~/.ssh/config. Check that the host key fingerprint matches what the host reports the first time you connect.

Do I need an account?

No. There is nothing to sign up for. Bellterm connects your phone straight to your own machines and has no server of ours in between, so there is no account, subscription or cloud storage.

Where are my passwords and keys stored?

In the iOS Keychain, or encrypted with a key held by the Android Keystore. They stay on the device, readable only on it, and are never uploaded. Your host list and the fingerprints you trusted are kept in a protected file inside the app.

How do I remove what Bellterm saved?

Delete a node to remove that host's details, and delete a key to remove its private key. Deleting the app removes its files too. iOS can keep Keychain items after an app is deleted, so delete saved passwords and keys in the app first if you want them gone for good. There is no account to delete, because there is no account.

Terminal text looks wrong

Try another colour scheme in settings, and check the font size. Nerd Font glyphs need a font that has them; import your own font if the bundled ones do not match your prompt.
