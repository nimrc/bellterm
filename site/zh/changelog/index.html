更新日志

Android 版本，最新的在前。Android 应用会自动提示新版本；TestFlight 上的 iOS 测试版会在之后的构建中带上同样的改动。

1.1.3

2026 年 11 月 19 日 · Android · GitHub 上的发布

  • 扩展按键行新增 Shift。先点 Shift 再点按键，就能在触屏上发送 Shift+← 等组合键，例如 Codex 的 Shift+← 或 Shift+Tab。它和 Ctrl、Alt 一样只对下一个按键生效，可以和它们组合，再点一次即可取消。

1.1.2

2026 年 11 月 17 日 · Android · GitHub 上的发布

  • 应用内的更新日志。设置里新增“更新日志”页面，按版本从新到旧列出改动，标出当前安装的版本，并可跳转到本页。

1.1.1

2026 年 11 月 16 日 · Android · GitHub 上的发布

  • Herdr 保存的机器。主机上的 Herdr 用 herdr machine add 保存过 SSH 机器时，会话抽屉会在“机器”里列出它们，主机排在最前，和 Herdr 自己的侧边栏一样。点按一台即可打开它的工作区。
  • Bellterm 经由主机连接这些机器：用的是主机自己的 SSH 密钥、配置和 known_hosts，机器不需要再信任手机的密钥。
  • 打开过的机器会留在节点列表里，标为“经”某台主机，删除主机时一起删除。
  • 主机连不上某台机器时，Bellterm 会显示主机上 SSH 给出的错误。

1.1.0

2026 年 11 月 16 日 · Android · GitHub 上的发布

  • Windows 主机。支持通过 OpenSSH 连接 Windows 机器，默认 shell 为 cmd.exe 或 PowerShell 均可。
  • 在应用中安装或更新 Herdr。主机上没有 Herdr，或版本太旧时，点按“安装 Herdr”或“更新 Herdr”。Bellterm 会运行 Herdr 自己的 herdr update --handoff，把正在运行的会话交接给新版本；或者运行它的安装脚本：install.sh，Windows 上是 install.ps1。

Bellterm 可以配合 Herdr 使用，但与 Herdr 或 herdr.dev 没有任何隶属、背书或支持关系。
