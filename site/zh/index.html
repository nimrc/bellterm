手机只是一扇窗，会话由 Herdr 掌管。

Bellterm 不运行你的终端。它像桌面客户端一样连接到你机器上的 Herdr 守护进程，把 Herdr 发来的画面画出来。信号断了、锁屏了、关掉 App 都没关系：窗格和 agent 照常运行，回来时接着看就行。

Bellterm

用 libghostty-vt 绘制 Herdr 的窗格，发送你的按键和触摸，并把守护进程的 agent 提醒带到你面前，在 Android 上以系统通知送达。

SSH，需要时经过跳板机
herdr remote-client-bridge

你的机器

运行 Herdr 守护进程，保存你的工作区、标签页、窗格和 agent。Bellterm 不会在上面启动或停止任何东西，只在你要求时安装或更新 Herdr。

在手机上做你在 Herdr 里做的事。

按 Herdr 的布局原样显示，再配上手机需要的操作。

Agent

  • 侧边栏里显示每个 agent 的状态：工作中、需要输入、已完成、空闲。
  • App 在后台时，agent 需要你或任务完成会弹出通知。
  • 点一下 agent，直接跳到它的窗格。
  • 工作区显示分支、领先和落后的提交数，以及 worktree。
  • 长按标签页或工作区即可重命名或关闭。

终端

  • libghostty-vt 负责字形簇、宽字符和颜色。
  • 扩展按键行：Esc、Tab、可锁定的 Ctrl 和 Alt，以及按住连发的方向键。
  • 中文输入直接在光标处组字，也支持实体键盘。
  • Nerd Font 图标、十套配色、双指缩放、长按复制。

SSH

  • 跳板机可以像 ssh -J 一样串联，每一跳的主机密钥都会核对。
  • 密钥与证书：在手机上生成 Ed25519 密钥，或导入 RSA、ECDSA、Ed25519 密钥。
  • 导入 ~/.ssh/config：每个 Host 成为一个节点，ProxyJump 也会导入。
  • 密钥和密码在 iOS 上存入钥匙串，在 Android 上用 Android Keystore 中的密钥加密保存。

开始使用

你需要一台能通过 SSH 访问、装有 Herdr 0.9.0 或更新版本的机器。

  1. 安装 Bellterm

    iPhone 用户可通过 TestFlight 下载测试版，按页面提示安装。Android 用户可下载 APK。首次启动时，Bellterm 会为这台设备生成一把 Ed25519 密钥。

  2. 授权手机的密钥

    在“密钥与证书”中复制公钥，添加到主机上。也可以改用你的 SSH CA 为它签发证书。

    echo 'ssh-ed25519 AAAA… bellterm@Pixel7' >> ~/.ssh/authorized_keys

  3. 添加节点并连接

    把主机添加为节点，或导入你的 SSH 配置。第一次连接时请核对主机密钥指纹。如果这个会话还没有运行 Herdr 服务，在主机上运行 herdr 启动一个。

系统要求

手机
iOS 测试版的兼容性要求请查看 TestFlight。Android 需要 10（API 29）或更新版本，支持 arm64 和 x86_64。
主机
Herdr 0.9.0 或更新版本，以及 /bin/sh。不支持只提供 PowerShell 的 Windows 主机。
跳板机
允许 TCP 转发的 SSH 即可，不需要别的。

Bellterm 可以配合 Herdr 使用，但与 Herdr 或 herdr.dev 没有任何隶属、背书或支持关系。
