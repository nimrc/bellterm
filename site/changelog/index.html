Changelog

Android releases, newest first. The Android app offers each one on its own; the iOS beta on TestFlight picks up the same changes in a later build.

1.1.1

16 November 2026 · Android · Release on GitHub

  • Herdr's saved machines. When Herdr on a host has saved SSH machines with herdr machine add, the session drawer lists them under Machines, with the host first, as Herdr's own sidebar does. Tap one to open its workspaces.
  • Bellterm reaches a machine through its host: the host's own SSH keys, configuration and known hosts sign in, so the machine needs nothing new from your phone.
  • A machine you opened stays in the node list, shown via its host, and is removed together with the host.
  • When a host cannot reach one of its machines, Bellterm shows the error the host's SSH reported.

1.1.0

16 November 2026 · Android · Release on GitHub

  • Windows hosts. Connect to Windows machines over OpenSSH, whether their default shell is cmd.exe or PowerShell.
  • Install or update Herdr from the app. When a host has no Herdr, or one too old for Bellterm, tap Install Herdr or Update Herdr. Bellterm runs Herdr's own herdr update --handoff, which hands running sessions to the new version, or its installer: install.sh, or install.ps1 on Windows.

Bellterm works with Herdr but is not affiliated with, endorsed by, or supported by Herdr or herdr.dev.
